# 手機版工具列雙層常駐設計

日期：2026-08-16
狀態：已獲使用者確認

## 問題

手機直式畫面（~375px 寬）下，底部工具列無法使用：

1. 工具列預設 `transform: translateY(110%)` 隱藏，只有滑鼠 hover 或釘選才顯示；手機觸控沒有 hover，工具列浮不出來。
2. 即使叫出來，工具列是一整排橫向 flex，寬度超過手機螢幕，按鈕被切掉、無法捲動。

## 設計

手機（寬度 < 860px）採用「雙層工具列、常駐顯示」：

- 工具列永遠顯示在底部，取消 hover 隱藏機制（等同強制釘選）
- 移除底部 10px `#tb-edge` 邊緣條
- 隱藏釘選按鈕 `#tb-pin`（已常駐，無釘選意義）
- 內容以 CSS `flex-wrap` 折成兩排：
  - 第一排：新增、檔名切換、上一頁、頁碼、下一頁、手套、虛線框、放大鏡、筆、復原、清空、回整頁
  - 第二排：筆選項（形狀、8 色、粗細滑桿），常駐顯示
- 浮動面板位置調整，避免被兩排工具列蓋住：
  - 放大鏡形狀面板 `#mag-panel` 上調
  - 檔名下拉 `#doc-list` 位置同步調整

桌面版（>= 860px）維持現狀不變。

## 範圍

- 只改 `css/style.css`（新增/調整 media query）
- 不改 JS、不改 HTML 結構（flex-wrap 折行即可達成）
- 桌面版外觀不受影響

## 實作更新（2026-08-16）

驗證後發現手機 390px 寬無法把「所有工具按鈕 + 筆選項」放進兩排，因此調整：

- 手機版工具列固定 **兩排**：第一排 [新增+檔名 | 上一頁|頁碼|下一頁]，第二排 [手套|虛線框|放大鏡|筆 | 復原|清空|回整頁]
- 筆選項（形狀/顏色/粗細）改為**浮動面板** `#pen-panel`，選筆工具時才出現在工具列上方（手機版）；桌面版維持工具列內嵌、不顯示浮動面板
- 修復檔名下拉清單 `#doc-list` 溢出手機螢幕右緣的問題（原因：無 `max-width` + `left:0` 錨定）→ 改為 `position:fixed` 固定於視窗範圍內、工具列上方
- 放大鏡面板 `#mag-panel`、檔名下拉統一定位在兩排工具列上方（`bottom:112px`）
- 涉及檔案：`index.html`（新增 `#pen-panel`）、`js/app.js`（面板顯示時機與選項同步）、`css/style.css`
