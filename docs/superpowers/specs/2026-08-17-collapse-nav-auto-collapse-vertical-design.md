# 設計規格：收合模式換頁箭頭 ＋ 選工具自動收合 ＋ 側邊直式工具列

日期：2026-08-17
狀態：使用者已確認需求方向

## 一、背景與問題

現有收合機制：工具列最右側 `#tb-collapse` 收合後，底部中央出現單一小圓鈕 `#tb-expand`（☰），點擊展開。全螢幕進入自動收合、退出自動展開。

使用者回饋的四個需求：
1. **收合後要能直接換頁**：小圓鈕兩側加左右箭頭，點箭頭直接翻頁，不需展開工具列。
2. **選工具後自動收合**：點小圓鈕展開工具列、選完工具後要自動收合，除非按了鎖定（＝常駐開啟＋位置固定）。
3. **側邊直式**：工具列拖到左右側要改為直式；收合後小圓鈕停留在左右側。
4. **退出全螢幕維持收合**：esc 退出全螢幕後，小圓鈕不應消失（目前會自動展開，被視為 bug）。

## 二、設計

### 1. 小圓鈕改為三顆一排（換頁箭頭）

- 收合後的細標由單一 `#tb-expand` 改為一組三顆水平排列：`←`（上一頁）＋ `☰`（展開）＋ `→`（下一頁）
- 左右箭頭：`#tb-expand-prev`、`#tb-expand-next`，點擊直接 `gotoPage(doc.page ∓ 1)`（與 `#pg-prev`/`#pg-next` 相同邏輯）
- 中間 ☰ 鈕：`#tb-expand`（沿用現有），點擊展開工具列
- 三顆整體由容器 `#tb-mini` 包覆，樣式沿用現有圓鈕風格（圓角矩形，非圓形）

### 2. 鎖定＝常駐＋位置固定（兩合一）

現有 `#tb-pin` 目前僅鎖定位置（tb-locked 禁止拖動）。改為：

| 鎖定狀態 | 工具列行為 |
|---|---|
| 開啟（pinned） | 常駐開啟：選工具**不自動收合**；位置固定：不可拖動 |
| 關閉 | 選工具後**自動收合**；位置可拖動 |

- 視覺：鎖定開啟時 `#tb-pin` 藍色高亮（沿用現有 `.pinned` class）
- 語意：鎖定＝「工具列就固定在那裡使用，我不需要它縮回去」

### 3. 選工具後自動收合

- 四大工具鈕（手套/縮放/放大鏡/筆）點擊 → `setTool(tool)` 後：
  - 若未鎖定（!state.tbLocked）且工具列非收合 → `setToolbarCollapsed(true)`
- 鎖定開啟時不自動收合
- 快捷鍵 1/2/3/4 切換工具不觸發自動收合（鍵盤操作本來就在收合狀態下也能用，避免干擾連續操作）

### 4. 側邊直式工具列

- 拖動工具列時偵測位置：
  - 鬆手時左緣 ≤ 8px → 工具列貼左邊緣，轉**直式**（`flex-direction: column`），加 class `.edge-left`
  - 鬆手時右緣 ≥ 視窗寬−8px → 貼右邊緣，轉直式，加 class `.edge-right`
  - 其他位置 → 保持橫式，移除 edge class
- 直式工具列內容垂直排列，寬度固定（約 56px）
- 直式時筆選項群組（`.pen-options`）隱藏，改用浮動面板 `#pen-panel`（與手機版同一套機制）

### 5. 小圓鈕跟隨工具列位置

- 收合後 `#tb-mini` 的位置依工具列停靠位置決定：
  - 底部（橫式）：`bottom: 14px; left: 50%; transform: translateX(-50%)`（現況）
  - 左側直式：`left: 8px; top: 50%; transform: translateY(-50%)`，箭頭組垂直方向對齊側邊
  - 右側直式：`right: 8px; top: 50%; transform: translateY(-50%)`
- 透過 `#tb-wrap` 的 `edge-left` / `edge-right` class 控制 `#tb-mini` 位置

### 6. 退出全螢幕維持收合

- `fullscreenchange` 目前退出時 `setToolbarCollapsed(false)`（自動展開）。改為：
  - 進入全螢幕 → 自動收合（維持現況）
  - 退出全螢幕 → **維持收合狀態**（不自動展開）
- 使用者可點 `#tb-expand`（☰）展開

## 三、互動流程範例

**簡報者流程（未鎖定）：**
1. 簡報中 → 點收合鈕或按 F → 工具列收成 `← ☰ →` 三顆
2. 點 `→` 直接下一頁，`←` 上一頁
3. 點 ☰ 展開工具列 → 選「筆」→ 工具列自動收合，畫筆啟用
4. 想固定工具列 → 展開 → 點鎖定 → 選工具不再收合

**投影流程：**
1. 按 F 進全螢幕 → 工具列自動收合成 `← ☰ →`
2. esc 退出 → 維持收合，不擋畫面
3. 點 ☰ → 工具列展開 → 選工具 → 自動收合

## 四、技術實作重點

- `index.html`：
  - `#tb-expand` 包進 `#tb-mini` 容器，新增 `#tb-expand-prev`、`#tb-expand-next`
  - 版本號 `?v=20260817c` → `?v=20260817d`
- `css/style.css`：
  - `#tb-mini`：三顆一排容器，底部中央 / 左緣 / 右緣三種停靠位置
  - `#toolbar.edge-left` / `.edge-right`：直式排列
  - `.pen-options` 在直式隱藏
- `js/app.js`：
  - `#tb-expand-prev`/`#tb-expand-next` click → gotoPage
  - `setTool()` 內自動收合（未鎖定時）
  - 拖動結束偵測邊緣 → 加/移除 edge class
  - `fullscreenchange` 退出不自動展開

## 五、驗證

- `node --check js\app.js` 通過
- 本機瀏覽器手動測試：
  - 收合後三顆出現，← → 換頁、☰ 展開
  - 展開 → 選工具 → 自動收合（未鎖定）
  - 鎖定後選工具不收合、無法拖動
  - 拖到左/右邊緣 → 直式；拖回中間 → 橫式
  - 左/右側收合 → 小圓鈕停側邊
  - F 進全螢幕自動收合，esc 退出維持收合
  - 快捷鍵 1/2/3/4 不觸發自動收合
